# Awesome-Multi-User-Process-Orchestration

# Top Multi-User Process Orchestration Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Human-in-the-Loop Workflows, BPMN Modeling & Cross-Team Process Automation*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Multi-User Process Orchestration Tools**. These tools coordinate workflows that span multiple people, teams, and systems — routing tasks, managing approvals, enforcing business rules, and tracking process state — using visual modeling, role-based assignment, and durable execution engines.

**Examples** include Salesforce Flow Orchestrator, Camunda Cloud, Temporal Cloud, ProcessMaker, Kissflow, Appian Orchestration, Tonkean, Signavio, Nintex Workflow Cloud, and Catalytic (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom orchestration logic, and transparent process execution — ideal for enterprises, operations teams, and developers building data-sovereign workflow platforms.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Flow Orchestrator](https://www.salesforce.com/)**  
  Multi-step, multi-user workflow engine within Salesforce for coordinating approvals, tasks, and stages across departments.

- **[Camunda Cloud (Camunda 8)](https://camunda.com/)**  
  Managed workflow and decision automation platform based on Zeebe, supporting BPMN, DMN, and human task orchestration.

- **[Temporal Cloud](https://temporal.io/)**  
  Managed durable execution platform for orchestrating long-running, multi-step workflows across services and teams.

- **[ProcessMaker](https://www.processmaker.com/)**  
  Low-code BPM and workflow automation platform with visual process designer, forms, and multi-user task routing.

- **[Kissflow](https://kissflow.com/)**  
  No-code workflow and process automation platform with approvals, forms, and cross-departmental orchestration.

- **[Appian Orchestration](https://appian.com/)**  
  Enterprise low-code automation platform with process modeling, case management, and AI-driven orchestration.

- **[Tonkean](https://tonkean.com/)**  
  No-code process orchestration platform that coordinates people, systems, and data across business operations.

- **[Signavio](https://www.signavio.com/)**  
  Business process management suite with process modeling, mining, and workflow orchestration capabilities.

- **[Nintex Workflow Cloud](https://www.nintex.com/)**  
  Process automation platform with drag-and-drop workflow design, forms, and multi-user task assignment.

- **[Catalytic](https://www.catalytic.com/)**  
  Intelligent process automation platform combining workflow orchestration with AI-powered document and data extraction.

## Open-Source GitHub Projects

- **[Camunda Platform 7](https://github.com/camunda/camunda-bpm-platform)**  
  Leading open-source BPMN workflow and decision automation engine with human task management, forms, and REST API. Apache 2.0 licensed. Used by thousands of enterprises for mission-critical orchestration.

- **[Flowable](https://github.com/flowable/flowable-engine)**  
  Open-source BPMN, CMMN, and DMN engine for workflow and case management with multi-user task assignment, forms, and REST APIs. Apache 2.0 licensed.

- **[Activiti](https://github.com/Activiti/Activiti)**  
  Lightweight open-source BPMN engine for workflow automation with human task routing and Spring integration. Apache 2.0 licensed.

- **[jBPM](https://github.com/kiegroup/jbpm)**  
  Open-source business process management suite with BPMN 2.0 modeling, human tasks, and rule integration. Apache 2.0 licensed.

- **[Temporal](https://github.com/temporalio/temporal)**  
  Open-source durable execution platform for orchestrating long-running workflows with human-in-the-loop steps and multi-service coordination. MIT licensed.

- **[Zeebe](https://github.com/camunda/zeebe)**  
  Distributed workflow engine powering Camunda 8, designed for high-throughput, multi-user process orchestration. Apache 2.0 licensed.

- **[Apache Airflow](https://github.com/apache/airflow)**  
  Workflow orchestration platform with DAG-based scheduling, human approval operators, and multi-team coordination. Apache 2.0 licensed.

- **[Prefect](https://github.com/PrefectHQ/prefect)**  
  Modern workflow orchestration framework with Python-native flows, human-in-the-loop tasks, and dynamic scheduling. Apache 2.0 licensed.

- **[Kestra](https://github.com/kestra-io/kestra)**  
  Declarative orchestration platform with YAML workflows, human tasks, and 500+ plugins for multi-user automation. Apache 2.0 licensed.

- **[Windmill](https://github.com/windmill-labs/windmill)**  
  Open-source developer platform for building workflows and internal tools with approval steps and multi-user execution. AGPL-3.0 licensed.

- **[n8n](https://github.com/n8n-io/n8n)**  
  Fair-code workflow automation platform with visual builder, human approval nodes, and multi-user collaboration. Sustainable Use License.

- **[Node-RED](https://github.com/node-red/node-red)**  
  Flow-based programming tool for event-driven orchestration with multi-user dashboards and approval flows. Apache 2.0 licensed.

- **[Bonita](https://github.com/bonitasoft/bonita-engine)**  
  Open-source BPM platform with visual process modeling, human tasks, and connector framework for enterprise orchestration. GPL licensed.

- **[ProcessMaker Community](https://github.com/processmaker/processmaker)**  
  Open-source BPM and workflow automation with visual designer, multi-user task routing, and API integrations. AGPL licensed.

- **[Joget](https://github.com/jogetworkflow/jw-community)**  
  Open-source low-code/no-code platform with workflow engine, forms, and multi-user process orchestration. GPL licensed.

- **[Corteza](https://github.com/cortezaproject/corteza)**  
  Open-source low-code platform with workflow automation, CRM, and multi-user process management. Apache 2.0 licensed.

- **[Imixs-Workflow](https://github.com/imixs/imixs-workflow)**  
  Open-source BPM engine with human task management, forms, and event-driven workflow orchestration. GPL licensed.

- **[Rundeck](https://github.com/rundeck/rundeck)**  
  Open-source job scheduler and runbook automation with approval workflows and multi-user access controls. Apache 2.0 licensed.

- **[StackStorm](https://github.com/StackStorm/stacksorm)**  
  Event-driven automation platform with rules engine, workflows, and multi-user action orchestration. Apache 2.0 licensed.

### Additional Strong Open-Source Options

- **[Apache Camel](https://github.com/apache/camel)** — Integration framework with routing patterns adaptable for multi-step process orchestration.
- **[Apache NiFi](https://github.com/apache/nifi)** — Data flow automation with visual programming and multi-user process routing.
- **[Benthos](https://github.com/redpanda-data/benthos)** — Stream processing and integration tool with declarative pipelines for orchestration.
- **[Trigger.dev](https://github.com/triggerdotdev/trigger.dev)** — Open-source platform for background jobs and event-driven workflows with human steps.
- **[Inngest](https://github.com/inngest/inngest)** — Event-driven workflow engine with durable functions and multi-step orchestration.
- **[SpiffWorkflow](https://github.com/sartography/SpiffWorkflow)** — Python BPMN workflow engine with human task support and form integration.
- **[Viewflow](https://github.com/viewflow/viewflow)** — Reusable workflow library for Django with BPMN-like process orchestration.
- **[Workflow Core](https://github.com/danielgerlag/workflow-core)** — Lightweight .NET workflow engine with multi-user task and approval support.
- **[Elsa Workflows](https://github.com/elsa-workflows/elsa-core)** — .NET workflow library with visual designer and human-in-the-loop orchestration.
- **Message Queues** (RabbitMQ, Apache Kafka, NATS) for reliable task distribution across users and systems.
- **Identity Providers** (Keycloak, Authentik) for role-based task assignment and approval permissions.

**Frameworks for building custom systems**: Combine **Camunda** or **Flowable** for BPMN orchestration, **Temporal** for durable long-running workflows, **Kestra** for declarative pipelines, **Keycloak** for role management, and **PostgreSQL + Grafana** for process analytics to build a complete self-hosted multi-user orchestration stack.
